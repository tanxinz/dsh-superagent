## 复验方法

在完整仓库根目录、Harness 固定子模块已初始化的情况下执行：

```bash
node --test scripts/m0-preflight.test.mjs
node scripts/m0-preflight.mjs
```

预检退出码：0 = 这些有限检查得到 CANDIDATE；2 = BLOCKED；1 = 输入/读取/执行错误。即使退出 0，完整构建和测试仍为 NOT_RUN，运行时组合仍 UNTESTED，M0 仍 BLOCKED。预检不会安装依赖、启动 DSH、调用模型或访问外网，仅创建并清理临时 socket 目录；路径随脚本定位，不依赖调用者 cwd。当前 probe 面向 Linux/macOS，Windows 不作为已通过环境。

原始完整构建仍应在 Harness 目录按其声明版本执行：

```bash
npm exec --yes --package=pnpm@11.28.5 -- pnpm install --frozen-lockfile
npm exec --yes --package=pnpm@11.28.5 -- pnpm build
npm exec --yes --package=pnpm@11.28.5 -- pnpm test
```

以上是待执行命令，不是本批通过证据；换用其他候选版本后须读取该版本自己的 packageManager 和 lockfile，不能沿用这里的版本号。
