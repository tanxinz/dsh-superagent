4. P0-04 Browser：`ctx.browserUse` 只是 Provider 注册，不虚构统一 click API；隔离、断线与效果对账保留。
5. P0-05 数据外送：新增原始问题泄露、配置变更、目标边界和 SSRF；网络隔离仍需验证。
6. P0-06 版本：原 DSH 0.2.1-alpha.2 SuperAgent 与 rc.3 未组合验证，gitlink 未改。
7. P1-01—05：证据等级、错误分类、Safety 与业务授权分离、Schedule 与 Effects 分离、预算均写入设计及清单。
